<h1 align="center">Sesame 0.3.0 · Enrôler sans première connexion</h1>

Nouveauté de l'**administration**.

> **Légende** · 👤 nouveauté · ⚠️ à savoir

## 👤 Nouveauté

- 👤 **Enrôlement préalable** (ADR 0035) : dans **Utilisateurs → « Enrôler un utilisateur »**, saisissez la clé d'identité SSO (nom et e-mail facultatifs), puis ajoutez ses comptes applicatifs depuis sa page (« Ajouter un compte »). À sa première connexion, l'utilisateur retrouve ses applications sans autre démarche ; son nom et son e-mail sont alors remplacés par ceux du fournisseur d'identité.
- 🔎 La **liste** et la **recherche** des utilisateurs montrent aussi les utilisateurs connus sans compte (enrôlés ou déjà connectés).
- 📜 Nouvel événement d'**audit** : `user_enrolled`.

## ⚠️ À savoir

- ⚠️ La clé doit être **exactement** la valeur du claim configuré pour le portail (`oid`, `sub`, `preferred_username`…) : une clé erronée crée des comptes rattachés à personne.
- ⚠️ L'enrôlement **n'accorde aucun droit** par lui-même. Aucune migration.
- ⚠️ Le changement est dans l'image **`sesame-admin`** uniquement.

## 🚀 Mettre à jour

```sh
# Docker Compose : dans le dossier du kit
sed -i 's/^SESAME_VERSION=.*/SESAME_VERSION=v0.3.0/' .env
docker compose pull && docker compose up -d
```

Sur AWS : `sesame_version = "v0.3.0"` puis `terraform apply`.
