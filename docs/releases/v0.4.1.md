<h1 align="center">Sesame 0.4.1 · Supprimer un utilisateur</h1>

<p align="center"><em>Retirez définitivement un utilisateur et tous ses accès depuis l'administration.</em></p>

---

Nouveauté de l'**administration** seule.

> **Légende** · 🗑️ nouveauté · ⚠️ à savoir

## 🗑️ Nouveauté

- 🗑️ **Suppression d'un utilisateur** : sur la page d'un utilisateur (Utilisateurs), le bouton « Supprimer l'utilisateur » (avec confirmation) efface les identifiants de **tous ses comptes** dans le coffre et le registre, y compris ceux d'applis dont le descripteur a disparu, ainsi que son profil, son enrôlement par e-mail, le rattachement de son identité SSO, ses suspensions, ses demandes d'accès et ses sessions ouvertes (déconnexion immédiate).
- 📜 **Audit** : `credential_deleted` pour chaque identifiant supprimé, puis `user_deleted` ; une notification « administration sensible » est déposée.

## ⚠️ À savoir

- ⚠️ La suppression est **définitive**. Si la personne se reconnecte, elle redevient un utilisateur inconnu, sans compte ; l'e-mail d'un enrôlement supprimé peut être enrôlé de nouveau.
- ⚠️ Si le coffre est indisponible, l'opération s'interrompt (échec audité) sans toucher au registre ; elle se relance sans effet de bord.
- ⚠️ Aucune migration. Seule l'image **`sesame-admin`** change (les autres sont reconstruites à l'identique).

## 🚀 Mettre à jour

```sh
# Docker Compose : dans le dossier du kit
sed -i 's/^SESAME_VERSION=.*/SESAME_VERSION=v0.4.1/' .env
docker compose pull && docker compose up -d
```

Sur AWS : `sesame_version = "v0.4.1"` puis `terraform apply`.
