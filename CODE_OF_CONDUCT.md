# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

## En bref

Nous voulons que la participation à Sesame soit une expérience accueillante et sans
harcèlement pour tout le monde, quels que soient l'âge, la taille, le handicap visible ou
invisible, l'origine ethnique, les caractéristiques sexuelles, l'identité ou l'expression de
genre, le niveau d'expérience, l'éducation, le statut socio-économique, la nationalité,
l'apparence, la religion ou l'orientation sexuelle.

**Comportements attendus** : bienveillance et empathie, respect des opinions et des
expériences différentes, critiques constructives données et reçues avec élégance,
reconnaissance de ses erreurs, attention portée à ce qui est le mieux pour la communauté.

**Comportements inacceptables** : langage ou images à caractère sexuel, attaques personnelles,
commentaires insultants ou dégradants, trolling, harcèlement public ou privé, publication
d'informations privées d'autrui (adresse, e-mail…) sans permission explicite, et tout
comportement raisonnablement considéré comme inapproprié dans un cadre professionnel.

## Portée

Ce code s'applique à tous les espaces du projet (issues, pull requests, discussions, revues de
code) et lorsqu'une personne représente officiellement le projet.

## Signalement

Signalez tout comportement inacceptable aux mainteneurs de façon privée, via le signalement
privé de GitHub (onglet **Security**, **Report a vulnerability**, en précisant qu'il s'agit du
code de conduite) ou directement à un mainteneur. Tous les signalements sont examinés
rapidement et équitablement, dans le respect de la confidentialité de la personne qui signale.

## Application

Selon la gravité, les mainteneurs peuvent : adresser un rappel privé, un avertissement, exclure
temporairement ou définitivement une personne des espaces du projet. Les lignes directrices
détaillées sont celles du Contributor Covenant 2.1.
