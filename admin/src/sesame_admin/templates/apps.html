Ajouter une application

Les applications sont décrites par des fichiers versionnés dans Git (dossier descriptors/), relus par merge request, et non créées depuis cette interface.

  1. Copier descriptors/TEMPLATE.yaml.example en descriptors/<id>.yaml et le compléter.
  2. Le valider avec un compte de test : sesame-onboard verify descriptors/<id>.yaml.
  3. Reporter l'empreinte : sesame-onboard fingerprint descriptors/<id>.yaml.
  4. Fusionner la merge request, puis redémarrer le portail, le proxy et cette interface.

L'application apparaît alors ici ; ses comptes se gèrent via « Gérer les comptes ».
